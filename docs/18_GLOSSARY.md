# 18 — Glossary

| Term | Definition |
|---|---|
| Alpha | Reproducible expected return above relevant baseline after realistic costs and uncertainty |
| Arm epoch | Unique runtime generation during which PAPER order authority is enabled |
| CASH | Explicit decision to hold capital and take no new exposure |
| Champion | Manually approved active strategy artifact for an alpha family |
| Challenger | Immutable research/shadow candidate that cannot trade unless promoted |
| Confidence | Out-of-sample calibrated support for an outcome/edge estimate, not a raw model score |
| Counterfactual | Recorded outcome for an eligible decision not executed, evaluated without changing history |
| CPCV | Combinatorial purged cross-validation for dependent financial observations |
| Data watermark | Exact event/sequence boundary used to form a decision |
| Decision snapshot | Immutable causal market/account/features view used for one decision |
| Evidence bundle | Reproducible package of data/code/config/results required for promotion review |
| Fail-closed | Reject/block/halt when required truth or control is unavailable |
| Gross notional | Absolute market value of exposure before netting |
| HALTED | No new exposure; existing exposure follows explicit protection/reconciliation policy |
| Holdout | Sealed dataset reserved for final unbiased estimation |
| Idempotency | Repeating an operation does not create an additional logical effect |
| Leverage ceiling | Maximum gross-notional/equity ratio; not a target or risk budget |
| Open risk | Pessimistic loss to protective exit or worse declared scenario, including costs |
| PAPER | Simulated/demo order operation with no real capital authorization |
| Probation | Reduced-risk state after an eligible manual resume |
| Purge/embargo | Removal/separation of overlapping/dependent samples around test boundaries |
| Reconciliation | Comparison and resolution of local order/position/account state against venue truth |
| Regime | Declared market condition grouping used for support and robustness analysis |
| SENTRY | Deterministic risk/integrity gate with veto authority |
| Shadow | Decisions recorded against live market state without sending orders |
| Slippage | Difference between decision/reference price and achieved fill attributable to execution |
| Strategy manifest | Immutable identity of code, features, parameters, evidence, and allowed scope |
| Tail loss | Loss in rare/adverse scenarios beyond ordinary variance |
| Venue adapter | Translation layer between canonical contracts and exchange-specific protocols |
